# Demo Git | Exercícios de HTML

Repositório de estudos com duas páginas HTML: `coffbreak.html` e `coffbreak2.html`. A segunda apresenta uma tela com o aviso **Voltamos Já!**.

## Como visualizar
Abra qualquer um dos arquivos `.html` em um navegador moderno.

## Objetivo
Praticar versionamento com Git e construção de páginas simples para a web.

**Tipo:** estudos e experimentos, não uma aplicação de produção.
